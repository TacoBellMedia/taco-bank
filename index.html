HOW THE ESTIMATE WORKS

The Cloudflare Worker reads the configured StateCraft Treasury account's transaction history and filters transactions whose memo/description contains the configured note marker. It then estimates each counterparty's physical-note position from the direction and value of those transactions.

This is deliberately labeled an estimate. It cannot observe notes moved without a Treasury-visible transaction, so the figures should be used as market intelligence rather than an authoritative bank balance.
